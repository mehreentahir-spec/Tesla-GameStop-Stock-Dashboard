# 📈 StockVision

### Tesla & GameStop Market Insights Dashboard

An interactive and visually attractive stock market dashboard designed to explore and compare the stock performance and revenue trends of **Tesla** and **GameStop**.

## 🚀 Live Dashboard

👉 [View StockVision Live Dashboard](https://mehreentahir-spec.github.io/Tesla-GameStop-Stock-Dashboard/)

## 📊 Dashboard Features

- Tesla and GameStop stock comparison
- Historical stock price visualization
- Quarterly revenue analysis
- Interactive charts
- Key performance indicators
- Company-wise dashboard navigation
- Responsive and modern dark-themed design
- Easy-to-understand market insights

## 🏢 Companies Covered

### Tesla

Tesla is an electric vehicle and clean energy company. The dashboard presents Tesla's historical stock prices and revenue trends.

### GameStop

GameStop is a video game and entertainment retailer. The dashboard presents GameStop's historical stock prices and quarterly revenue trends.
