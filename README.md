# 📊 Market Insights Dashboard

An interactive and visually engaging stock market dashboard designed to explore company performance through stock prices, revenue, and key financial statistics.

The dashboard presents Tesla and GameStop data in a modern dark-themed interface with glowing cards, interactive charts, company selection, and responsive styling.

---

## ✨ Features

- 🚘 Tesla and GameStop company selection
- 📈 Interactive stock price history chart
- 💰 Quarterly revenue visualization
- 📊 Key performance statistics
- 🎨 Modern dark dashboard interface
- 🌈 Neon-style colours and glowing cards
- 🖱️ Interactive Plotly charts
- 📱 Responsive layout
- 🌐 Browser-based dashboard
- 🧩 Reusable HTML, CSS, and JavaScript structure

---

## 🚀 How to Run

### Option 1: Open the HTML dashboard

1. Download or clone this repository.
2. Open the project folder.
3. Double-click:

```text
market_insights_dashboard.html
```

4. The dashboard will open in your browser.

---

### Option 2: Run through Jupyter Notebook

1. Open Jupyter Notebook.
2. Open `dashboard_code.ipynb`.
3. Run the dashboard cell.
4. The HTML dashboard will be generated.
5. The dashboard will open automatically in your default browser.

The project is based on a stock-price and revenue visualization workflow for Tesla and GameStop.
